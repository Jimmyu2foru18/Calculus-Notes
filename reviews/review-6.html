Review: Applications I

This sheet covers the related rates method in detail, finding absolute extrema on closed intervals, the first derivative test for increasing/decreasing behavior, and the full curve-sketching procedure.

The Related Rates Method

Related rates problems connect multiple changing quantities through an equation. The key is differentiating with respect to time $t$.

\[ \frac{d}{dt}[f(\text{quantities})] = \frac{df}{dt} \]
Differentiate the relationship w.r.t. time
  1. Draw a diagram and label all changing quantities.
  2. Write the geometric/physical equation relating them.
  3. Differentiate both sides with respect to $t$.
  4. Substitute known values and solve for the unknown rate.

Do NOT substitute constants before differentiating. Values that are constant at one instant may be changing. Substitute only after differentiating.

Related Rates: Pythagorean Setup

For problems involving right triangles (ladder, boat, airplane):

\[ x^2 + y^2 = s^2 \implies 2x\frac{dx}{dt} + 2y\frac{dy}{dt} = 2s\frac{ds}{dt} \]
Differentiating $x^2 + y^2 = s^2$

Related Rates: Volume Problems

For filling/draining containers, use the volume formula for the shape:

ShapeVolume FormulaKey Rate
Cylinder$V = \pi r^2 h$$\dfrac{dV}{dt} = \pi r^2 \dfrac{dh}{dt}$ (if $r$ constant)
Cone$V = \frac{1}{3}\pi r^2 h$Relate $r$ and $h$ via similar triangles first
Sphere$V = \frac{4}{3}\pi r^3$$\dfrac{dV}{dt} = 4\pi r^2 \dfrac{dr}{dt}$

Conical tanks: Always relate $r$ and $h$ using similar triangles ($r/h = R/H$) before differentiating to eliminate one variable.

Absolute Extrema on a Closed Interval

The Extreme Value Theorem guarantees that a continuous function on $[a, b]$ attains both a maximum and minimum.

\[ \text{Closed Interval Method: } \max/\min \in \{f(a), f(b), f(c_1), f(c_2), \dots\} \]
Where $c_i$ are critical numbers in $(a, b)$

Extreme Value Theorem: If $f$ is continuous on closed interval $[a, b]$, then $f$ attains an absolute maximum and absolute minimum on $[a, b]$.

Finding Critical Numbers

A critical number $c$ of $f$ is a number in the domain of $f$ where $f'(c) = 0$ or $f'(c)$ does not exist.

StepAction
1Find $f'(x)$
2Solve $f'(x) = 0$
3Find where $f'(x)$ is undefined (in domain of $f$)
4Evaluate $f$ at critical numbers and endpoints

Absolute vs. Relative Extrema

TypeDefinition
Absolute max$f(c) \ge f(x)$ for all $x$ in domain
Absolute min$f(c) \le f(x)$ for all $x$ in domain
Relative max$f(c) \ge f(x)$ for all $x$ near $c$
Relative min$f(c) \le f(x)$ for all $x$ near $c$

Fact: An absolute extremum is also a relative extremum (if interior to the domain). Relative extrema can occur at interior critical points.

First Derivative Test

Use the sign of $f'$ to determine where $f$ is increasing or decreasing, and to classify critical points.

Sign of $f'$Behavior of $f$
$f' > 0$ on $(a, b)$$f$ is increasing on $(a, b)$
$f' < 0$ on $(a, b)$$f$ is decreasing on $(a, b)$
$f'$ changes $+$ to $-$ at $c$Relative maximum at $c$
$f'$ changes $-$ to $+$ at $c$Relative minimum at $c$
$f'$ does not change sign at $c$No extremum at $c$

Number Line Test

Mark critical values on a number line and test the sign of $f'$ in each interval:

\[ \text{If } f'(x) > 0 \text{ on } (-\infty, -4) \cup (3, \infty) \text{ and } f'(x) < 0 \text{ on } (-4, 3) \] \[ \text{Then } f \text{ is increasing on } (-\infty, -4) \cup (3, \infty), \text{ decreasing on } (-4, 3) \]

Curve Sketching Procedure

  1. Domain: Find all $x$-values where $f$ is defined.
  2. Intercepts: Find $x$-intercepts ($f(x) = 0$) and $y$-intercept ($f(0)$).
  3. Symmetry: Check even ($f(-x) = f(x)$), odd ($f(-x) = -f(x)$), or neither.
  4. Asymptotes: Find vertical, horizontal, and oblique asymptotes.
  5. First derivative: Find critical numbers, intervals of increase/decrease, and relative extrema.
  6. Second derivative: Find inflection points and intervals of concavity.

Remember: Curve sketching is a checklist. Go through all steps systematically — missing one can give an incomplete or incorrect sketch.

Concavity and Inflection Points

Concavity is determined by the second derivative:

ConditionMeaning
$f''(x) > 0$Concave up
$f''(x) < 0$Concave down
$f''$ changes sign at $c$Inflection point at $(c, f(c))$

Second Derivative Test caveat: If $f''(c) = 0$ or $f''(c)$ does not exist, the test is inconclusive. Use the First Derivative Test instead.

Second Derivative Test

At a critical number $c$ where $f'(c) = 0$:

\[ f''(c) > 0 \implies \text{relative minimum at } c \] \[ f''(c) < 0 \implies \text{relative maximum at } c \] \[ f''(c) = 0 \text{ or DNE} \implies \text{inconclusive} \]

Practice Problems

  1. For $f(x) = \dfrac{x^2 - 3}{2x - 4}$, find the domain, intercepts, asymptotes, and classify all discontinuities.
  2. Find the critical numbers of $f(x) = x^3 - 3x^2 + 4$ and determine absolute extrema on $[-1, 3]$.
  3. Use the First Derivative Test to classify the critical points of $f(x) = x^3 - 6x^2 + 9x + 1$.
  4. Find intervals of increase/decrease and concavity for $f(x) = x^4 - 4x^3 + 6x^2$.
  5. Sketch the graph of $f(x) = \dfrac{x^2}{x^2 - 1}$ using all seven steps.
  6. Find all relative extrema of $f(x) = \sin x + \cos x$ on $[0, 2\pi]$.
  7. Find inflection points of $f(x) = x^4 - 4x^3 + 6x^2$.
  8. Use IVT to show $x^5 - x - 1 = 0$ has a root in $(1, 2)$.
  9. A spherical balloon is inflated at $10 \text{ cm}^3/\text{s}$. Find $\dfrac{dr}{dt}$ when $r = 5$ cm.
  10. A 10 ft ladder slides down a wall at 1 ft/s. Find how fast the bottom moves when it is 6 ft from the wall.

Solution Sketch: $f(x) = \dfrac{x^2}{x^2 - 1}$

Figure: $f(x)=x^2/(x^2-1)$ has VAs at $x=\pm1$, HA $y=1$, x-intercept at $(0,0)$, and no relative extrema (the point $(0,0)$ is a local maximum in the middle branch but $f(0)=0$).
