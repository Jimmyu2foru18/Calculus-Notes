Review: Integration Techniques

This sheet covers u-substitution, area between curves (vertical and horizontal slices), the disk and washer methods for volumes of revolution, and the cylindrical shells method.

The Substitution Rule (u-Substitution)

Substitution reverses the chain rule. If $u = g(x)$, then $du = g'(x)\, dx$ and:

\[ \int f(g(x))g'(x)\, dx = \int f(u)\, du = F(u) + C = F(g(x)) + C \]
General substitution rule

Substitution Method Steps

  1. Identify $u$ as the inner function (often in parentheses, under a root, or in the denominator exponent).
  2. Compute $du = \dfrac{du}{dx}\, dx$.
  3. Solve for $dx$ and substitute into the integral.
  4. Complete the problem in terms of $u$.
  5. If bounds were given, convert them to $u$-values and evaluate directly. Otherwise, convert back to $x$ before substituting bounds.

Strategy: If you can't spot the substitution immediately, try rewriting the integrand using algebra or trig identities to expose a composition of functions.

Worked Examples: u-Substitution

Evaluate $\int (3x^4 + 5x^2 + 10)\, dx$:

\[ \int (3x^4 + 5x^2 + 10)\, dx = \frac{3}{5}x^5 + \frac{5}{3}x^3 + 10x + C \]
Direct power rule (no substitution needed)

Evaluate $\int \dfrac{5x^3 - 3x + 2}{x^5}\, dx$ by rewriting first:

\[ \int (5x^{-2} - 3x^{-4} + 2x^{-5})\, dx = -\frac{5}{x} + \frac{1}{x^3} - \frac{1}{2x^4} + C \]
Rewriting as powers of $x$

Area Between Curves — Vertical Slices

If $f(x) \ge g(x)$ on $[a, b]$, the area between the curves is:

\[ A = \int_a^b [f(x) - g(x)]\, dx \]
Area between curves (vertical slices)

Procedure: Find intersection points (these are the bounds $a$ and $b$), then subtract the lower curve from the upper curve.

Area Between Curves — Horizontal Slices

If the curves are more naturally expressed as $x = f(y)$ and $x = g(y)$, integrate with respect to $y$:

\[ A = \int_c^d [f(y) - g(y)]\, dy \]
Area between curves (horizontal slices)
OrientationWhen to Use
Vertical slices ($dx$)Upper and lower functions given as $y = f(x)$
Horizontal slices ($dy$)Left and right functions given as $x = g(y)$

Area Example

Find the area between $y = x^2$ and $y = x + 2$:

\[ x^2 = x + 2 \implies x^2 - x - 2 = 0 \implies (x-2)(x+1) = 0 \implies x = -1, 2 \] \[ A = \int_{-1}^2 [(x+2) - x^2]\, dx = \left[\frac{x^2}{2} + 2x - \frac{x^3}{3}\right]_{-1}^2 = \frac{9}{2} \]
Area between parabola and line

Disk Method

When a region is revolved around an axis and there is no gap between the region and the axis, use disks:

\[ V = \pi \int_a^b [R(x)]^2\, dx \quad \text{(rotation about a horizontal axis)} \]
Disk method — vertical slices

When to use: Use the disk method when the axis of rotation is a boundary of the region. The cross-section is a solid disk of radius $R(x)$.

Washer Method

When there is a gap between the region and the axis of rotation (inner radius $r$, outer radius $R$):

\[ V = \pi \int_a^b \left([R(x)]^2 - [r(x)]^2\right)\, dx \]
Washer method — outer radius squared minus inner radius squared

Common mistake: The integrand is $R^2 - r^2$, NOT $(R - r)^2$. The area of a washer is $\pi(R^2 - r^2)$, not $\pi(R - r)^2$.

Disk/Washer Example

Find the volume when $y = \sqrt{x}$ on $[0, 4]$ is revolved about the $x$-axis:

\[ V = \pi \int_0^4 (\sqrt{x})^2\, dx = \pi \int_0^4 x\, dx = \pi\left[\frac{x^2}{2}\right]_0^4 = \pi \cdot 8 = 8\pi \]
Disk method example

Find the volume when the region between $y = x$ and $y = x^2$ on $[0, 1]$ is revolved about the $x$-axis:

\[ V = \pi \int_0^1 \left(x^2 - (x^2)^2\right)\, dx = \pi \int_0^1 (x^2 - x^4)\, dx = \pi\left[\frac{1}{3} - \frac{1}{5}\right] = \frac{2\pi}{15} \]
Washer method example

Cylindrical Shells Method

When revolving around a vertical axis, use shells with radius $r(x)$ and height $h(x)$:

\[ V = 2\pi \int_a^b r(x)h(x)\, dx \]
Shell method — vertical axis of rotation

When to use shells: Shells are often easier when the axis of rotation is parallel to the axis of the slices (vertical slices for vertical axis of rotation). You do NOT need to solve for $x$ in terms of $y$.

Shell Method Setup

For vertical axis of rotation ($x = k$):

QuantityFormula
Radius$r(x) = |x - k|$ (distance from slice to axis)
Height$h(x) = f(x) - g(x)$ (top minus bottom)
Circumference$2\pi r(x)$
Volume element$dV = 2\pi r(x)h(x)\, dx$

Choosing a Method

ScenarioRecommended Method
Axis of rotation is a boundary; easy to integrateDisk method
Gap between region and axis; easy to integrateWasher method
Vertical axis; solving for $x$ is hardCylindrical shells
Horizontal axis; $y$ as function of $x$ is easyDisk or washer

Shells about the y-axis: When rotating about the $y$-axis ($x = 0$), the radius is simply $r(x) = x$.

Practice Problems

  1. Evaluate $\int (3x^4 + 5x^2 + 10)\, dx$ using basic integration rules.
  2. Evaluate $\int (14x^3 - \sqrt[4]{x})\, dx$ by rewriting as powers.
  3. Evaluate $\int \left(\dfrac{2}{3x^5} + \dfrac{3}{4x^2}\right)\, dx$.
  4. Evaluate $\int \dfrac{5x^3 - 3x + 2}{x^5}\, dx$.
  5. Evaluate $\int \left(\dfrac{1}{x} + \sqrt{x^7}\right)\, dx$.
  6. Evaluate $\int (3\sin x - 4e^x + x^3)\, dx$.
  7. Evaluate $\int (3\sec^2 x + 2\cos x)\, dx$.
  8. Find the area between $y = x^2$ and $y = x + 2$ on $[-1, 2]$.
  9. Find the volume when $y = \sqrt{x}$ on $[0, 4]$ is revolved about the $x$-axis (disk method).
  10. Find the volume when the region between $y = x$ and $y = x^2$ on $[0, 1]$ is revolved about the $x$-axis (washer method).
  11. Find the volume when the region under $y = x^2$ on $[0, 1]$ is revolved about the $y$-axis (shell method).
  12. Evaluate $\int x\cos(x^2)\, dx$ using u-substitution.
  13. Evaluate $\int x\sqrt{x^2+1}\, dx$ using u-substitution.
