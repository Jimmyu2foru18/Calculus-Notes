5.3 — Volumes Using Cylindrical Shells

The cylindrical shell method offers an alternative to disks and washers. Instead of slicing the solid perpendicular to the axis of rotation, we slice it parallel to the axis. Each slice becomes a thin cylindrical shell. When integrated, these shells give the exact volume of the solid.

Key Formula

Cylindrical Shell Method (rotation about the y-axis)

If $y = f(x) \ge 0$ on $[a, b]$, rotating the region under $f$ about the $y$-axis produces a solid whose volume is:

$$V = 2\pi \int_a^b x \cdot f(x)\,dx$$

A typical shell has:

  • radius $= x$ (distance from the $y$-axis)
  • height $= f(x)$
  • thickness $= dx$

The shell volume element is $dV = 2\pi(\text{radius})(\text{height})(\text{thickness})$.

Shell Method (rotation about the x-axis)

When rotating about the $x$-axis, use horizontal strips $x = g(y)$ on $[c, d]$:

$$V = 2\pi \int_c^d y \cdot g(y)\,dy$$

A typical shell has radius $= y$, height $= g(y)$, and thickness $= dy$.

Worked Example — Sphere via Shell Method

Example 5.3.1

Derive the volume of a sphere of radius $R$ by rotating the semicircle $y = \sqrt{R^2 - x^2}$ about the $y$-axis using the shell method.

Step 1: Identify bounds. The semicircle spans $x \in [0, R]$.

Step 2: Apply the shell formula.

$$V = 2\pi \int_0^R x\sqrt{R^2 - x^2}\,dx$$

Step 3: Use substitution. Let $u = R^2 - x^2$, so $du = -2x\,dx$ and $x\,dx = -\frac{du}{2}$.

$$V = 2\pi \int_{x=0}^{x=R} x\sqrt{R^2 - x^2}\,dx = 2\pi \int_{u=R^2}^{u=0} \sqrt{u} \cdot \left(-\frac{du}{2}\right)$$ $$= \pi \int_0^{R^2} u^{1/2}\,du = \pi \left[\frac{2}{3}u^{3/2}\right]_0^{R^2}$$ $$= \frac{2\pi}{3}(R^2)^{3/2} = \frac{2\pi}{3}R^3$$

Step 4: Wait — this is only half the sphere! The semicircle $y = \sqrt{R^2 - x^2}$ from $x = 0$ to $x = R$ represents only one quarter of the full circle in the first quadrant. Rotating this quarter-circle about the $y$-axis produces only half a sphere.

To get the full sphere, double the result: $$V = 2 \cdot \frac{2\pi}{3}R^3 = \frac{4\pi}{3}R^3$$

Answer: The volume of a sphere is $\boxed{\dfrac{4\pi}{3}R^3}$.

Worked Example — Shell Method for a Cone

Example 5.3.2

Find the volume of the solid obtained by rotating the region bounded by $y = x$, $y = 0$, and $x = 4$ about the $x$-axis using the shell method.

Step 1: Express $x$ in terms of $y$: $x = y$ on $[0, 4]$ for $y$. The region in terms of $y$ is $x = y$ from $y = 0$ to $y = 4$.

Step 2: Apply the shell method about the $x$-axis.

$$V = 2\pi \int_0^4 y \cdot x\,dy = 2\pi \int_0^4 y^2\,dy$$

Step 3: Evaluate.

$$V = 2\pi \left[\frac{y^3}{3}\right]_0^4 = 2\pi \cdot \frac{64}{3} = \frac{128\pi}{3}$$

Answer: The volume is $\boxed{\dfrac{128\pi}{3}\text{ cubic units}}$.

When to Use Shells vs. Washers

Comparison Table

Method Best For Strip Direction
Disk Solid with no hole; axis is boundary Perpendicular to axis
Washer Solid with a hole Perpendicular to axis
Shell When washers require solving for the inverse function Parallel to axis

A good rule of thumb: if rotating about the $y$-axis and the function is $y = f(x)$, the shell method avoids solving $x = f^{-1}(y)$.

Practice Problems

  1. Use the shell method to find the volume generated by rotating $y = x^2$ on $[0, 3]$ about the $y$-axis.
  2. Use the shell method to find the volume generated by rotating $y = \sqrt{x}$ on $[0, 4]$ about the $x$-axis.
  3. Find the volume of the solid obtained by rotating the region between $y = x$ and $y = x^2$ about the $y$-axis using shells. Compare with the washer method answer from the previous section.

Study Tips

  • Shells are especially powerful when rotating about the $y$-axis and the function is given as $y = f(x)$ — no inversion needed.
  • Always identify radius, height, and thickness before writing the integral.
  • The shell circumference $2\pi r$ is easy to forget; set up $dV = 2\pi r h\,dx$ explicitly until it becomes automatic.
  • When in doubt, sketch both the region and one representative shell.
