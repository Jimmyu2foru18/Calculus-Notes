2.2 — Reading Limits from Graphs and Tables

What Does a Limit Tell Us?

A limit answers the question: What value does the function approach as $x$ gets closer and closer to a specific point?

The key word is approach. We do not care what happens at the point itself — only what happens nearby.

Reading Limits Graphically

To find a limit from a graph:

  1. Trace from the left: Follow the curve as $x$ approaches the target value from the left side. What $y$-value does it get close to?
  2. Trace from the right: Follow the curve as $x$ approaches from the right side. What $y$-value does it get close to?
  3. Compare: If both sides approach the same value, that is the limit. If they approach different values, the limit does not exist.

Visual patterns to recognize:

  • Hole: The curve approaches the same height from both sides, but the point is missing. The limit still exists.
  • Jump: The left and right sides approach different heights. The limit does not exist.
  • Vertical asymptote: The curve shoots upward or downward without bound. The limit does not exist.
  • Horizontal asymptote: The curve flattens out toward a specific height as $x \to \pm\infty$.

Estimating Limits Numerically

When a graph is not available, build a table of values approaching the target from both sides:

$x$ (from left)$f(x)$$x$ (from right)$f(x)$
target $-$ 0.1...target $+$ 0.1...
target $-$ 0.01...target $+$ 0.01...
target $-$ 0.001...target $+$ 0.001...

If the values converge to the same number from both sides, that is the limit.

Worked Examples

Example 2.2.1 — Reading a Graph

Problem: From the graph below, find the limit as $x$ approaches 2.

Figure 2.2.1 — Function with a Hole

Solution: As $x$ approaches 2 from the left, the curve rises toward $y = 5$. As $x$ approaches 2 from the right, the curve also approaches $y = 5$. Both sides agree, so:

$$\lim_{x \to 2} f(x) = 5$$

Note that $f(2) = 7$ (the filled dot), but the limit depends only on the approach path, not the actual value at the point.

Example 2.2.2 — Jump Discontinuity

Problem: Find the limit as $x$ approaches the jump point.

Figure 2.2.2 — Jump Discontinuity

Solution: Approaching from the left, the curve heads toward $y = -1$. Approaching from the right, the curve heads toward $y = 1$. Since $-1 \neq 1$, the left and right limits disagree:

$$\lim_{x \to 0^-} f(x) = -1, \quad \lim_{x \to 0^+} f(x) = 1$$

Therefore, the two-sided limit does not exist.

Example 2.2.3 — Vertical Asymptote

Problem: Evaluate the one-sided limits of $\frac{1}{x}$ as $x$ approaches 0.

Figure 2.2.3 — Vertical Asymptote

Solution:

  • As $x$ approaches 0 from the right ($x > 0$), $\frac{1}{x}$ grows without bound upward: $\lim_{x \to 0^+} \frac{1}{x} = +\infty$.
  • As $x$ approaches 0 from the left ($x < 0$), $\frac{1}{x}$ dives without bound downward: $\lim_{x \to 0^-} \frac{1}{x} = -\infty$.

Because the one-sided limits disagree in sign, the two-sided limit $\lim_{x \to 0} \frac{1}{x}$ does not exist. The line $x = 0$ is a vertical asymptote.

Practice Problems

Exercises

Problem 1 — Reading a graph

From a graph with a hole at $x = -1$ where both branches approach $y \approx 2.5$, find $\lim_{x \to -1} f(x)$.

Answer: The left and right branches both approach $y \approx 2.5$, so the limit is about $2.5$.

Problem 2 — When the limit differs from the function value

Suppose $g(4) = 7$ but $\lim_{x \to 4} g(x) = 3$. Sketch a rough graph illustrating this situation.

Problem 3 — Numerical estimation

Estimate $\lim_{x \to 0} \dfrac{\sin x}{x}$ by evaluating the function at $x = \pm 0.1, \pm 0.01, \pm 0.001$.

Answer: The values approach $1$ from both sides, so the limit is $1$.

Study Tips

1. Always trace from both sides of the target point. A limit exists only when the left-hand and right-hand approaches agree.

2. The actual value at the point does not matter for the limit. A hole, jump, or removable discontinuity can still have a well-defined limit.

3. Draw a quick sketch whenever possible. Visual intuition guides your algebraic work.

4. For rational functions, factor first to identify holes versus vertical asymptotes.

5. Use tables of values when graphs are unavailable; approaching from both sides is essential.
