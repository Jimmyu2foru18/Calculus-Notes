2.1 — The Idea of Limits

Calculus is fundamentally built on one idea: change. To understand how quantities change, we need a precise way to describe behavior near a point — not necessarily at the point. That is the role of the limit.

Intuitive Definition

We write the limit of the function value as the input approaches a specific number equals a target value, written in mathematical notation as $\lim_{x \to c} f(x) = L$. In plain language: as the input variable $x$ gets arbitrarily close to the target input $c$ (from either side), the output values of the function $f(x)$ get arbitrarily close to the target output $L$. The actual function value at $c$ may be different from $L$, or the function may not even be defined at that point.

Key Definitions

Definition — Limit

Let $f$ be a function (a rule that assigns an output to each input) defined on an open interval (a continuous range of inputs) containing $c$, except possibly at $c$ itself. We say the limit of the function as the input approaches $c$ equals $L$ if for every small positive tolerance $a$ there exists a small positive distance $d$ such that

$$0 < |x - c| < d \;\Longrightarrow\; |f(x) - L| < a.$$

In plain English: this means we can trap the graph of the function inside a horizontal band of height $2a$ centered at $L$ by restricting the input $x$ to a punctured neighborhood (a neighborhood with the center point removed) of radius $d$ around $c$, excluding $c$ itself.

Example 2.1.1

Consider the function $f$ shown below. It has a "hole" at $x = 2$, meaning $f(2)$ is undefined, but the curve approaches height $y = 5$ from both sides.

Solution: As $x$ approaches $2$ from either side, the $y$-values approach $5$. Therefore,

$$\lim_{x \to 2} f(x) = 5.$$

Note that $f(2)$ itself does not exist — the open circle shows the function is undefined there. The limit depends only on nearby values, not the value at $c$.

Study Tips

1. Always check both sides of $c$. A limit exists only when the left-hand and right-hand limits agree.

2. The value $f(c)$ is irrelevant to the limit. A hole, jump, or removable discontinuity can still have a well-defined limit.

3. Draw a quick sketch whenever possible. Visual intuition guides algebraic work.
